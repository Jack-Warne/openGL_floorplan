# OpenGL_floorplan

Using OpenGl and ModernGL to create a 3D render of a floor plan and calculate the number of materials needed to build the house to scale.

To download necessary libraries, go to the file location of the repository and type cmd into the path. Then ```run pip install -r requirements.txt```
